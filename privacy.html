시행일: 2026년 10월 12일

1. 사용하는 구글 권한

노래방 리모콘은 구글 로그인 시 "이 앱으로 만든 구글 드라이브 파일만 보기·수정"(drive.file) 권한 하나만 요청합니다. 이 권한으로는 사용자가 이 프로그램으로 만든 "노래모음" 스프레드시트에만 접근할 수 있고, 드라이브의 다른 파일·메일·연락처 등에는 접근할 수 없습니다.

2. 처리하는 정보

사용자가 직접 입력한 노래 제목, 가수, 유튜브 링크를 사용자 본인의 "노래모음" 스프레드시트에 저장합니다. 로그인 정보(인증 토큰)는 사용자 PC 안에만 저장되며 개발자나 제3자 서버로 전송되지 않습니다.

3. 제3자 제공

어떤 정보도 개발자나 제3자에게 전송·판매·공유하지 않습니다. 프로그램은 별도 서버를 운영하지 않으며, 구글 API와 유튜브에만 직접 연결합니다.

4. 연결 해제와 삭제

구글 계정 설정의 "타사 앱 및 서비스"에서 언제든 연결을 해제할 수 있습니다. "노래모음" 시트는 사용자 드라이브의 일반 파일이므로 직접 삭제할 수 있습니다. 프로그램을 지우면 PC에 저장된 토큰도 함께 지울 수 있습니다(%APPDATA%\KaraokeRemote).

5. Google API 서비스 사용자 데이터 정책

이 프로그램이 Google API에서 받은 정보의 사용은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.
